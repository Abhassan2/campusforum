# Project - Campusforum

Campusforum is a social media platform exclusively for campus students to share content, achievements, coding challenges, and build meaningful connections.

## 🚀 Features
- Responsive design with Next.js + Tailwind CSS
- JWT authentication and secure routes
- Cloudinary integration for media uploads
- MongoDB with Mongoose schema relations
  
## 🛠 Tech Stack
- Frontend: Next.js, Tailwind CSS
- Backend: Node.js, Express, MongoDB
- Auth: JWT
- Deployment: on Vercel
